Overview
This is a React.js webapp that allows for retrieving data from a backend server from MLAB and Ripe Atlas to use this data for viewing visually in charts


Installation and Setup

Prerequisites
-Node.js: Make sure you have Node.js installed (v22.6 or higher)
-npm: automatically bundled with Node.js

Installation Steps
1. Clone the repository
    using the following on the terminal:
    git clone https://gitlab.cs.uct.ac.za/lwxeth001/capstone-npip

2. Navigate into the project directory
    using the following on the terminal:
    cd CAPSTONE-NPIP

3. Install the dependencies
    using the following on the terminal:
    npm install

4. Start the development Server
    Once the dependencies are installed, start the React development server
    using the following on the terminal:
    npm start

This will automatically start the React application in development mode and should automatically open in your default browser, if it does not open in your browser, manually navigate to:
    http://localhost:3000

To create a production build, follow steps 1 through 3 and then instead of using 'npm start', use 'npm run build'
